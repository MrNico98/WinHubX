# Sicurezza

## Segnalazione responsabile

Non pubblicare vulnerabilità non risolte, exploit, token o dati personali nelle issue. Usa una segnalazione privata tramite il meccanismo di sicurezza del repository GitHub. Se il canale privato non è disponibile, apri una issue minimale chiedendo un contatto riservato senza dettagli tecnici sfruttabili.

Indica versione, sistema operativo, componente coinvolto, impatto, passaggi di riproduzione sicuri e una possibile mitigazione.

## Ambito

Sono rilevanti vulnerabilità in codice, aggiornamento, download, gestione dei privilegi, parsing di file e distribuzione. I problemi relativi a servizi esterni vanno segnalati ai rispettivi proprietari.

## Buone pratiche per gli utenti

Scarica solo dalle release ufficiali, verifica gli hash pubblicati e mantieni Windows aggiornato. WinHubX non distribuisce certificati, chiavi, credenziali o bypass di licenze.
